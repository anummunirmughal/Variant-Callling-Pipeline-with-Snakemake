# Variant-Callling-Pipeline-with-Snakemake

This repository contains a Snakemake pipeline for variant calling from FASTQ cell line data. It automates the process from quality control to variant annotation using various bioinformatics tools. Below is a comprehensive guide to installing tools, setting up data, and running the pipeline.

## Requirements

## 1. Software Prerequisites

Operating System: Linux/MacOS

Package Manager: conda (recommended for tool installations)

## 2. Tools Used in the Pipeline

Snakemake
FastQC
Trimmomatic
BWA
Samtools
GATK
ANNOVAR

## Installation Guide

### 1. Install Conda
Install Miniconda:

wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

bash Miniconda3-latest-Linux-x86_64.sh

Follow the prompts to complete the installation and activate conda:

source ~/.bashrc

### 2. Create and Activate a Conda Environment

conda create -n variant_calling python=3.9 -y

conda activate variant_calling

### 3. Install Required Tools

conda install -c bioconda snakemake fastqc trimmomatic bwa samtools gatk4 -y

### 4. Install ANNOVAR
Download and extract ANNOVAR:

wget http://www.openbioinformatics.org/annovar/download/annovar.latest.tar.gz

tar -zxvf annovar.latest.tar.gz

mv annovar/ project/annovar/

Download annotation databases:

cd project/annovar

perl annotate_variation.pl --buildver hg38 --downdb refGene humandb/

perl annotate_variation.pl --buildver hg38 --downdb cytoBand humandb/

perl annotate_variation.pl --buildver hg38 --downdb exac03 humandb/

perl annotate_variation.pl --buildver hg38 --downdb -webfrom annovar dbsnp152

perl annotate_variation.pl -buildver hg38 -downdb -webfrom annovar gnomad211_exome

## Reference Data Setup
### 1. Download Reference Genome
For human data, download GRCh38 from the GATK Resource Bundle or UCSC Genome Browser:

wget -c ftp://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_38/GRCh38.primary_assembly.genome.fa.gz

gunzip GRCh38.primary_assembly.genome.fa.gz

mv GRCh38.primary_assembly.genome.fa reference/GRCh38.fasta

### 2. Index the Reference Genome
Create FASTA index file:

samtools faidx reference/GRCh38.fasta

Create GATK sequence dictionary:

gatk CreateSequenceDictionary -R reference/GRCh38.fasta -O reference/GRCh38.dict

3. Download Known Variants
Download known variant datasets (e.g., dbSNP and Mills and 1KG) from the GATK Resource Bundle:

wget -c ftp://gsapubftp-anonymous@ftp.broadinstitute.org/bundle/hg38/dbsnp_146.hg38.vcf.gz

wget -c ftp://gsapubftp-anonymous@ftp.broadinstitute.org/bundle/hg38/Mills_and_1000G_gold_standard.indels.hg38.vcf.gz

mv dbsnp_146.hg38.vcf.gz reference/

mv Mills_and_1000G_gold_standard.indels.hg38.vcf.gz reference/

Index these files:

tabix -p vcf reference/dbsnp_146.hg38.vcf.gz

tabix -p vcf reference/Mills_and_1000G_gold_standard.indels.hg38.vcf.gz

## Running the Pipeline

### 1. Test the Pipeline
Run a dry-run to check for errors:

snakemake --cores 4 --dry-run

### 2. Execute the Pipeline
Run the pipeline with:

snakemake --cores 4

Replace 4 with the number of CPU cores you wish to allocate.

### 3. View Output
Check the output/ directory for generated files. Key outputs include:

Trimmed FASTQ files
BAM alignment files
VCF files with called variants
Annotated variants
Customising the Pipeline

Modify the Snakefile to:

Change input FASTQ file paths.
Adjust tool parameters (e.g., Trimmomatic trimming thresholds, GATK variant filtering thresholds).
Add or remove steps as per your project requirements.

Troubleshooting
Tool Not Found: Ensure all tools are installed and $PATH is correctly set.
File Not Found: Verify directory structure and file paths in the Snakefile.
Reference Mismatch: Ensure all reference files (FASTA, VCF) use the same genome build (e.g., hg38)
